# DXdev

Small, open tools for people and AI agents who work together on real work. Each one does one thing, runs on plain Python, and starts with a README you can read in a minute.

## Repos

| Repo | What it does | Try it |
|---|---|---|
| [agent-guardrails](https://github.com/dxdev-inc/agent-guardrails) | Small hooks that stop a coding agent before it makes a known mistake. | `git clone https://github.com/dxdev-inc/agent-guardrails.git` |
| [agent-memory](https://github.com/dxdev-inc/agent-memory) | Keeps a folder of agent memory files healthy: size checks, recall, duplicate cleanup you can undo. | `git clone https://github.com/dxdev-inc/agent-memory.git` |
| [agent-scorecard](https://github.com/dxdev-inc/agent-scorecard) | Measures how much of the work you hand to agents actually finished, and how much of that you can trust. | `git clone https://github.com/dxdev-inc/agent-scorecard.git` |

Every README opens with what the tool does and how to run it. Technical detail sits further down, or in linked docs.
